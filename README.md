# AdAdminTool

**AdAdminTool** — административная консоль (WPF, .NET) для работы с компьютерами домена Active Directory: просмотр списка ПК из AD, проверка их доступности, сбор системной информации удалённых машин через PsExec, снятие скриншотов рабочего стола и подключение по VNC.

## Возможности

- 🖥 **Список компьютеров домена** — получение всех объектов `computer` из Active Directory (`System.DirectoryServices`, LDAP-запрос к контроллеру домена).
- 🌐 **Проверка доступности (Online/Offline)** — ping, при неудаче — TCP-подключение к порту 445 (SMB).
- 📋 **Сбор системной информации удалённого ПК** — через PsExec выполняются команды (`systeminfo /fo csv` и др.): ОС, аптайм, процессор, память, диск и т.п.
- 👤 **Информация об активном пользователе** — определение активного сеанса (`query session`), имя пользователя и время простоя (idle time).
- 📸 **Удалённый снимок экрана** — захват скриншота рабочего стола пользователя на удалённой машине с отображением в интерфейсе и возможностью обновления.
- 🔌 **Подключение по VNC** — запуск внешнего VNC Viewer к выбранному компьютеру (настраиваемые порт и пароль).
- 🧭 **Фильтрация и поиск** по списку компьютеров, статусная строка, консоль вывода операций.

## Требования

- Windows 10/11 (или Windows Server) в составе домена Active Directory;
- [.NET 10 SDK](https://dotnet.microsoft.com/download) для сборки;
- [PsExec](https://learn.microsoft.com/sysinternals/downloads/psexec) (Sysinternals);
- VNC-сервер на целевых машинах (для подключения по VNC) и VNC Viewer (например, TightVNC/UltraVNC) — опционально;
- Приложение авторизуется в AD автоматически под учётной записью, под которой выполнен вход в Windows (Kerberos/NTLM, без пароля в конфиге). Права на чтение AD и удалённое выполнение ADMIN$ берутся от этой учётной записи.

## Конфигурация

Приложение читает настройки из файла **`appsettings.json`** в рабочей директории (рядом с `AdAdminTool.exe`). Файл не включён в репозиторий — создайте его самостоятельно:

```json
{
  "DcHost": "dc01.contoso.local",
  "Domain": "contoso.local",
  "BaseDn": "DC=contoso,DC=local",
  "PsExecPath": "C:\\Tools\\psexec.exe",
  "VncViewerPath": "C:\\Tools\\vncviewer.exe",
  "VncPort": 5900,
  "VncPassword": "********"
}
```

| Параметр | Описание |
|---|---|
| `DcHost` | Хост/имя контроллера домена для LDAP-запросов |
| `Domain` | Имя домена |
| `BaseDn` | Базовый DN поиска (например, `DC=contoso,DC=local`) |
| `PsExecPath` | Полный путь к `psexec.exe` |
| `VncViewerPath` | Путь к исполняемому файлу VNC Viewer |
| `VncPort` | Порт VNC на целевых машинах (по умолчанию 5900) |
| `VncPassword` | Пароль для подключения по VNC |

> ⚠️ Храните `appsettings.json` в защищённом месте: файл содержит пароли в открытом виде.

## Сборка и запуск

```bash
git clone <URL-репозитория>
cd AdAdminTool

dotnet restore
dotnet build -c Release
dotnet run --project AdAdminTool
```

Или откройте `AdAdminTool.slnx` в Visual Studio и выполните сборку/запуск (F5).

Для публикации одного файла:

```bash
dotnet publish AdAdminTool -c Release -r win-x64 --self-contained false
```

## Использование

1. Запустите приложение — список компьютеров загрузится из Active Directory автоматически.
2. Выберите компьютер в списке: выполнится проверка доступности и сбор системной информации.
3. Вкладки/панели покажут сведения о ПК и об активном пользователе (включая время простоя).
4. Нажмите кнопку снятия скриншота для захвата рабочего стола удалённой машины; кнопку обновления — для повторного захвата.
5. Кнопка **VNC** открывает подключение к выбранному компьютеру через внешний VNC Viewer.

## Примечания

- Для удалённого выполнения команд через PsExec на целевых машинах должны быть доступны SMB (порт 445) и служба «Планировщик заданий»/ADMIN$-доступ (либо включённая Remote Registry, в зависимости от настроек Windows).
- Возможно появление предупреждений EULA PsExec при первом запуске — примите лицензионное соглашение, запустив `psexec.exe /accepteula` под используемой учётной записью.

## Лицензия

Внутренний инструмент для административных целей. Использует Sysinternals PsExec и сторонние VNC-клиенты в соответствии с их лицензиями.
